## Limitation

The model only sees messages ≥ 2 days before closest approach. When an encounter's geometry changes sharply inside those 2 days (as in the examples above), the early messages carry no warning and neither the rule nor the model can flag it. The operator would learn of it only from later messages, so the dashboard must keep re-assessing as new messages arrive rather than treating a 2-day-out Safe as final.
